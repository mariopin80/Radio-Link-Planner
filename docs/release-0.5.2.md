# Radio Link Planner 0.5.2 — atualização de conformidade para validação

Novembro de 2026 · Mario Pin — PU2PTU

## Alterações

- Inclusão dos créditos e avisos exigidos pela licença Copernicus WorldDEM-30 nos relatórios de enlace e cobertura (HTML, Markdown e PDF), inclusive nos exemplos publicados.
- Link para a licença do OpenStreetMap nos mapas interativos de enlace, cobertura e seleção de coordenadas.
- Seção **Licenças e fontes de dados** no menu **Sobre**, com acesso aos avisos de terceiros.
- Inclusão dos avisos de licença do NTIA ITM e Py2001 no instalador Windows, além do aviso existente do Py1812 e da licença MapLibre.
- Inventário preliminar das dependências, origem dos recursos gráficos, consulta preparada à ITU e análise de conformidade de uso dos tiles do OpenStreetMap.
- Minutas para futuras edições proprietárias: Community gratuita (uso pessoal), Personal (uso pessoal) e Pro (uso profissional), além de minutas de termos de uso e privacidade.
- Testes automatizados adicionais para presença dos créditos de dados geográficos e avisos legais.

## Downloads

- **RadioLinkPlanner-0.5.2-Windows-x64-Setup.exe**: instalador Windows x64.

## Importante

Esta é uma **versão de validação**, ainda não comercial. Nenhum mecanismo de cobrança, registro ou bloqueio Community/Personal/Pro está ativo nesta versão; as minutas em `legal/` **não são contratos vigentes**.

Continuam pendentes a confirmação formal da ITU para downloads automatizados de dados em software comercial, a verificação prática dos cabeçalhos HTTP dos tiles OSM no Windows, a conferência integral das licenças transitivas do pacote compilado e a revisão jurídica dos termos futuros. Os arquivos digitais integrais da ITU **não** são distribuídos no instalador.
