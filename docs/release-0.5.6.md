# Radio Link Planner 0.5.6

Pré-lançamento para Windows x64.

- **Cobertura** — em **Mapa e relatório**, clique em uma célula para consultar margem, S estimado, condição de visada, distância e azimute. A consulta funciona nas três visualizações e lê os dados da grade calculada. #26
- **Visada** — o pop-up mostra **Bloqueada**, **Insuficiente** ou **Livre** conforme o resultado da análise de Visada e Fresnel. Um travessão indica que o dado está indisponível.
