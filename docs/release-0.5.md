# Radio Link Planner 0.5 — versão para validação

Outubro de 2026 · Mario Pin — PU2PTU · mariopin@gmail.com

## Alterações

- Tempo restante apresentado uma única vez junto à barra de progresso da cobertura. O rodapé mostra a etapa atual.
- Interface, mensagens, seletor de coordenadas, mapas, gráficos, Markdown e relatórios PDF em português, inglês, espanhol, francês e alemão.
- Seleção de idioma na tela inicial com bandeiras do Brasil, Reino Unido, Espanha, França e Alemanha e nomes nativos; preferência lembrada ao reabrir.
- Aba Sobre com versão 0.5, mês/ano de lançamento, desenvolvedor, indicativo de chamada e contato por e-mail.
- Instalador nos mesmos cinco idiomas, com os ícones próprios nos atalhos e atualização sobre a 0.4.3.
- Projetos de cobertura salvos com opções independentes do idioma; leitura dos projetos anteriores preservada.
- Tabelas PDF com quebra de linhas para acomodar os textos traduzidos.
- Correção da quantidade de células calculadas no PDF de cobertura, identificada na validação dos relatórios.

## Downloads

- **RadioLinkPlanner-0.5-Windows-x64-Setup.exe**: instalador para Windows x64.
- **RadioLinkPlanner-0.5-Windows-x64.zip**: versão portátil.
- **SHA256SUMS.txt**: verificação dos arquivos.

Não exige Python instalado. Os dados digitais ITU-R são obtidos da fonte oficial e mantidos no perfil do usuário.

Esta pré-versão será usada nos testes de uso antes da decisão de lançar a 1.0.
