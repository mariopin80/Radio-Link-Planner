# PU2PTU - Radio Link Planner 0.6.2

Pré-lançamento para Windows x64.

- O nome **PU2PTU - Radio Link Planner** aparece na interface, nos relatórios, no instalador e nos atalhos do Windows.
- **Novo Enlace** e **Nova Cobertura** voltam a sugerir uma sensibilidade de recepção editável para cada modo. O programa salva as personalizações por modo e, no enlace, por terminal. #49
- A meta inicial de disponibilidade de **Novo Enlace** é de 50%. Preencha as coordenadas e os dados da instalação antes de calcular.

## Downloads

- `RadioLinkPlanner-0.6.2-Windows-x64-Setup.exe` — instalador Windows
- `SHA256SUMS.txt` — hash SHA-256 do instalador
