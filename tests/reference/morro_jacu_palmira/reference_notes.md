# Caso de referência Morro do Jacu – Palmira

Coordenadas e parâmetros transcritos do relatório do Radio Mobile fornecido
pelo usuário. O perfil foi reextraído diretamente do Copernicus GLO-30 em
2026-07-28, com aproximadamente 30 m entre amostras.

Dois pixels isolados de valor zero ocorreram exatamente nas sobreposições das
tiles em aproximadamente 7,11 km e 110,38 km. Como os pixels adjacentes eram
terreno elevado e os pontos estavam no interior continental, os valores foram
interpolados entre os vizinhos imediatos. A operação está documentada para
manter a rastreabilidade.

As referências ITM usam a biblioteca C++ oficial da NTIA no commit registrado
no código. P.1812 e P.2001 usam implementações Python traduzidas das versões de
referência, com os produtos digitais oficiais da ITU.
